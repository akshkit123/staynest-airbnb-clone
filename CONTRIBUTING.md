## Contribution & Git Workflow
1. **Branching Strategy**: Each member develops features on their designated personal branch.
2. **Commit Policy**: Regular atomic commits with descriptive commit messages.
3. **Peer Review**: Features merged into `main` after verification of backend and frontend integration.
